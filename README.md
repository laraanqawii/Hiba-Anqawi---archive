# أرشيفي — أرشيف الاختبارات والتحضير والخطط

موقع بسيط لحفظ وتنظيم ملفات المعلمة (اختبارات، تحضير، خطط) في مكان واحد، مع إمكانية رفع الملفات الفعلية (Word / PDF / صور) وليس فقط روابط.

## كيف يعمل التخزين؟

المشروع يشتغل بوضعين تلقائيًا:

1. **وضع محلي (افتراضي، بدون أي إعداد):** البيانات والملفات تُحفظ داخل متصفحك فقط (IndexedDB). يعمل فورًا لكنه غير متزامن بين الأجهزة، وقد تُفقد البيانات إذا مسحتِ بيانات المتصفح.
2. **وضع سحابي (Firebase - موصى به):** بعد تعبئة بيانات مشروع Firebase الخاص بك في ملف `firebase-config.js`، يتحول الموقع تلقائيًا لحفظ كل شيء على حساب Firebase الخاص بك (مجاني ضمن الحدود المعقولة لمعلمة واحدة). هذا يعني وصول لنفس الأرشيف من أي جهاز، ونسخة احتياطية حقيقية لملفاتك.

## إعداد Firebase (مرة واحدة فقط - حوالي 10 دقائق)

1. افتحي https://console.firebase.google.com وسجّلي بحساب Google.
2. أنشئي مشروعًا جديدًا (Add project) — أعطيه أي اسم مثل `hiba-archive`.
3. من القائمة الجانبية: **Build → Firestore Database → Create database** (اختاري "Start in production mode" ثم أي موقع قريب).
4. من القائمة الجانبية: **Build → Storage → Get started** (نفس الخطوات).
5. من إعدادات المشروع (⚙️ Project settings) → تبويب General → قسم "Your apps" → اضغطي أيقونة الويب `</>` وسجّلي تطبيقًا جديدًا. سيظهر لك كائن `firebaseConfig`.
6. انسخي القيم وألصقيها في ملف `firebase-config.js` مكان القيم `PASTE_...`.
7. من تبويب **Firestore Database → Rules** و **Storage → Rules**، فعّلي الوصول (لأنك المستخدمة الوحيدة، يمكنك مؤقتًا استخدام قاعدة تسمح بالقراءة/الكتابة بدون تسجيل دخول — راجعي `firestore.rules.txt` و `storage.rules.txt` المرفقين في هذا المشروع للقاعدة المقترحة، وهي مقيّدة بحجم الملف ونوعه لحمايتك من الاستخدام الخاطئ).

بعد هذه الخطوة، أعيدي تحميل الموقع — سيظهر إشعار صغير يؤكد أنه يعمل الآن بالوضع السحابي.

## النشر على GitHub Pages (استضافة مجانية)

راجعي خطوات الرفع أدناه في المحادثة، أو ملف `DEPLOY.md`.

## هيكل المشروع

```
index.html          الصفحة الرئيسية
styles.css           كل التنسيقات
app.js                منطق الموقع (عرض، بحث، حفظ)
firebase-config.js    بيانات مشروعك على Firebase (تعدّلينها مرة وحدة)
firestore.rules.txt   قاعدة أمان مقترحة لـ Firestore
storage.rules.txt     قاعدة أمان مقترحة لـ Storage
```
